# 农业病害细粒度图文对齐：BLIP 消融与配置规划

状态：讨论草案，2026-11-02。这里只规划，不包含可执行训练代码、模型权重或数据；尚未下载模型、安装依赖或开展实验。后续实现与正式运行前需冻结方案并验证。

## 1. 研究设定

先以香蕉三类为例，沿用现有训练/验证/测试划分（登记数 4800/600/600，实际读取时核对）；不再对数据做清洗。只检查读取、路径、标签映射及划分一致性，原图与原描述不改动。同一图像产生的文本和裁剪必须继承原 split。纯图像分类测试不得输入该图真实类别或逐图描述；给定短语定位是单独的图文任务。

候选骨干为 BLIP-1 图文检索模型 `BlipForImageTextRetrieval`，候选权重 `Salesforce/blip-itm-base-coco`；具体权重、revision、许可、processor、维度和加载信息均未验证。统一 checkpoint 初始化、划分和视觉预处理。当前只讨论 BLIP 内部消融，不代表完成外部方法主实验或证明创新性。

## 2. 冻结与 LoRA：先保守，后对照

首选**冻结全部预训练骨干原始参数**，仅训练指定 LoRA 和新增三类线性分类头；有图文损失的组再统一训练预训练 ITM 二分类头。分类使用视觉编码器输出第一个 token（`last_hidden_state[:, 0, :]`）接线性层，不依赖测试文字。具体输出约定在模型加载后核对。无图文损失的组 ITM 头不更新，其定位输出若有报告，须明确为未针对任务微调的匹配分支。

| 部分 | 初始方案 | 解释 |
| --- | --- | --- |
| 视觉编码器 | 原参数冻结；最后 4 个视觉 block 的 attention 合并 `qkv` 注入 LoRA | 同时影响 Q/K/V；不是仅 Q/V。 |
| 文本/融合编码器 | 原参数冻结；最后 4 个文本 block 的 cross-attention `query` 和 `value` 注入 LoRA | 仅在图文匹配分支产生有效梯度；纯分类组不宣称该分支被训练。 |
| 其他预训练参数 | 包括 embedding、LayerNorm、bias、MLP、池化/投影层均冻结 | 首轮不额外解冻最后一层；ITM 头例外如上。`vision_proj`、`text_proj` 在拟议 ITM 路径中冻结且不用。 |
| 新分类头 | 全量训练 | 各组结构与初始化规则一致。 |
| LoRA 超参数 | `r=8, alpha=16, dropout=0.05, bias=none` | 仅为起点，不是调优结论；最终数量以模块匹配清单为准。 |

本机 Transformers 4.57.6 源码中，候选完整模块路径模式为 `vision_model.encoder.layers.{i}.self_attn.qkv` 和 `text_encoder.encoder.layer.{i}.crossattention.self.{query,value}`。`i` 由实际层数计算为最后四层，不能假定一定是 8–11；cross-attention 是否存在由实际模型配置决定。不要用泛化的 `query` / `value` 名称匹配所有层，否则可能同时命中 self-attention。加载后打印精确命中名、维度与数量，理论上应为视觉 4 个、融合 8 个；不符即停止并检查，不静默继续。上述只是本机源码层级，实际权重及 PEFT 版本兼容性尚待验证。

冻结参数不等于自动关闭 dropout：各组按相同 `train/eval` 模式处理；优化器仅接收 `requires_grad=True` 参数。代码验收需打印各分支可训练名、数量与占比，并检查图文组分类、视觉 LoRA、融合 LoRA 与 ITM 头的梯度；纯分类组的融合分支无梯度属于预期。训练状态保存必须覆盖 LoRA、分类头、已训练 ITM 头、优化器、随机状态、配置、base revision 和 processor；明确使用 PEFT 的 `modules_to_save` 或单独保存头，做重载输出一致性检查。

LoRA 主要减少待更新参数和优化器状态，不保证整轮更快：视觉反向传播、激活、文本交互和多裁剪仍有成本。未来实测训练参数、峰值显存、每步吞吐及总 GPU 时间。若要回答“是否解冻”，在主设定固定后增加单因素对照：LoRA-only vs 在同一 LoRA 配置上额外解冻最后一个视觉 block；这比较的是增量，不是参数量相等的公平效率对照。可再比较参数预算接近的 LoRA-only 与选择性解冻，但需单独报告各自参数、显存及时间，不先假定谁更好。

## 3. 文本构造与匹配边界

按训练类别用代码批量映射固定模板，不调用大模型 API；详细描述直接使用数据包的 `blind_caption`，不重写原文。香蕉有非叶片样本，因此示例使用 sample：

```text
a photo of a banana sample with black sigatoka
a photo of a banana sample with fusarium wilt
a photo of a healthy banana sample
```

实际类别名以索引标签映射为准，运行前固定模板和映射。模板来自来源类别，不保证图中症状可见。细文本、裁剪和短语视图须保留 image ID、原文出处和 split；描述、抽出的短语都是弱标签，不自动等于视觉真值。记录最大 token 长度、截断率、短语数和配对数，按实际模型限制确定长度。

同类样本的模板相同，绝不能当成负例；模板可用跨类别配对作类别条件下的候选负例，但其并不自动代表严格的视觉语义不匹配。症状短语跨类也可能真实匹配，不能简单以不同图或不同类别判负；局部分支先设计保守筛选、忽略不确定对并明确假负例风险，**负例判定、抽取规则与空样本处理须在训练代码实现前单独定稿**。记录各组有效正负例与丢弃数，不把不确定硬标成负例。

## 4. 候选目标函数

`L = L_cls + λg L_global + λl L_local`。分类 `L_cls` 是三类交叉熵；`L_global` 是整图和文本的 ITM 匹配二分类交叉熵；`L_local` 候选为短语与多个图像裁剪的包级匹配损失。ITM 使用匹配与不匹配两个 logits；训练前确认 checkpoint 的标签索引和输出约定。

局部候选方案：取每个区域的 ITM 匹配 logit 差作为分数，归一化 log-sum-exp 聚合到图片—短语包，再对可信正包与筛选后的负包做二分类损失；聚合温度、区域采样、正负采样、有效项归一化与无有效短语时的处理必须先明确。正包仅依赖文本来自原图这一弱假设，采样裁剪也可能漏掉目标，无法保证所有正包正确。此式是拟议实现，BLIP 的原始 forward 不会自动提供这些训练损失。各损失按各自有效样本平均，`λg=0.2, λl=0.2` 只是候选初值，不表示梯度尺度相当；监控损失及梯度，仅用验证集在预先限定范围内确定系数。

## 5. 首批消融：先隔离问题

各组共同使用同一分类头初始化规则、数据、视觉 LoRA、图像预处理、分类损失和训练/选模预算；涉及图文任务的组采用一致的融合 LoRA 与 ITM 头训练策略。实际的文本、区域数和算力可能不同，须记录而非宣称完全相同。

| 组 | 训练损失与文本 | 比较用途 |
| --- | --- | --- |
| A | `L_cls`，无文字 | 纯视觉参考。 |
| B | `L_cls + λg L_global`，类别短模板 | 测试类别级文字监督。 |
| C | 同 B，但文本为类别模板 + 原始 blind 描述 | 与 B 比较增加描述，仍同时改变长度及语义信息。 |
| D | 同 B，但只用原始 blind 描述 | 与 C 比较是否附加类别名称。 |
| E | C + `λl L_local`，原文短语与区域候选 | 与 C 比较局部目标的组合效果；额外损失及计算不能忽略。 |
| F | C + 同系数短语整图匹配 | 和 E 用相同短语、匹配头、配对/更新预算与损失系数比较整图与区域；若用重复整图匹配区域次数，明示重复及梯度聚合方式。 |

E/F 尽量匹配有效短语、区域/整图前向数和损失归一化；不同视野与计算不能完全等同，要逐项报告。先以单种子小预算核验流程，再按资源完成关键对照；正式结论建议 3 个固定种子，报告每次与均值波动。后续单独做 LoRA `r=4/8/16`（`alpha=2r`）、不同适配位置、解冻对照；不同时改变多个核心因素。

## 6. 拟议训练与评价协议

- 训练初值：AdamW，weight decay 0.01；LoRA/ITM 学习率 `1e-4`，分类头 `5e-4`；最多 8 epoch，5% warmup、余弦衰减；物理 batch 4、累积 4（显存不足时调整物理 batch 并保持有效 batch）。这些均是待验证起点，固定调参预算；不保证 16 GB 显存可运行。
- 分辨率、token 上限和 processor 使用已验证 checkpoint 的配置；谨慎水平翻转，不能让含左右关系的描述与增强后的图像矛盾。局部裁剪候选、采样数、坐标映射与聚合温度在实现前固定，并保存到配置。
- 分类以验证集 Macro-F1 选模，测试报告 Accuracy、Macro-F1、各类指标与混淆矩阵；仅用图片预测。测试集不参与模型/阈值选择。
- 定位须有独立人工验证/测试标注（短语、可见/不存在/不确定及位置），以标注类型选择点命中或 IoU，并报告随机/中心基线与候选覆盖上限；没有独立位置真值时只能做定性分析，不能声称定位有效。
- 实现之前核查依赖及模型兼容性；之后先做少量样本的读取、梯度和保存恢复检查，再开展计划中的训练。当前这些步骤均未执行。

## 8. 研究边界和参考
